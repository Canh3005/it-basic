Sub-pillar 9.6 · Spring Boot

Backend với Spring Boot

Spring Boot là framework backend phổ biến nhất của hệ sinh thái Java — nền tảng của rất nhiều hệ thống ngân hàng, thương mại điện tử, viễn thông. Sub-pillar này dạy Spring Boot 3 trên Java 21 theo hướng hiểu cơ chế: container và DI, proxy và transaction, filter chain của Security, N+1 của JPA — rồi đi tới những thứ làm nên một hệ thống thật: bảo mật JWT, kiểm thử với Testcontainers, cache và message queue, microservices, Docker và Kubernetes.

Spring Boot 3 · Java 21 · 14 chương · ~10,700 dòng · 70 bài tập + 84 quiz

Học Spring Boot thế nào cho đúng

📋 Điều kiện đầu vào

Cần nắm sub-pillar Java chương 1-9 (OOP, Collections, Generics) và nên đã học Lambda/Stream, JDBC (chương 10, 13). Thêm kiến thức nền từ các trụ cột: Networking (HTTP, Auth), Database (SQL, transaction, index), OOP (SOLID).

⚠️ Về phiên bản và tài liệu trên mạng

Nhiều bài hướng dẫn vẫn dùng Spring Boot 2: javax.* (nay là jakarta.*), WebSecurityConfigurerAdapter (đã bị xoá ở Spring Security 6), RestTemplate, @MockBean. Sub-pillar này dùng Boot 3.x làm chuẩn. Khi copy code từ nơi khác, kiểm tra phiên bản trước.

Spring Boot trong bức tranh Pillar 9

  • Chương 7 (JPA & Transaction) ↔ Java Chương 13 (JDBC) — JPA là lớp trên JDBC; hiểu JDBC để hiểu SQL mà Hibernate sinh ra.
  • Chương 4-5, 9-10 ↔ Fullstack-ContactCenter (NestJS) — cùng bài toán REST/JWT/RBAC bằng hệ sinh thái Node.
  • Chương 12-14 ↔ DevOps và System Design — cache, queue, microservices, CI/CD, Kubernetes ở góc nhìn hạ tầng.

Xem vị trí sub-pillar này trong lộ trình Fullstack Developer (hướng B: Java + JavaScript).
